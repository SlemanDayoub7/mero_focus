# نطاق النسخة الأولى (MVP)

## ضمن النطاق

| الميزة | ملاحظات |
|---|---|
| مؤقت بومودورو قابل للتخصيص | مدة العمل/الراحة القصيرة/الراحة الطويلة، عدد الجولات قبل الراحة الطويلة |
| تتبع عادات أساسي | تكرار يومي/أسبوعي مخصص، تسجيل إنجاز يومي |
| ثيمات بصرية بسيطة | بدون نظام مودات/جيمفكيشن (راجع ADR-0005) |
| خلفيات قابلة للتخصيص | |
| أصوات قابلة للتخصيص | ضوضاء بيضاء أثناء الجلسة + صوت نهاية المؤقت |
| إحصائيات تفصيلية كاملة | بمستوى: ساعة، يوم، أسبوع، شهر، سنة، سنوات، فترة مخصصة — مجانية بالكامل، بدون أي قيود |
| تصدير PDF | تصدير الإحصائيات بصيغة PDF |
| قفل تطبيقات محددة | أثناء الجلسة فقط. حجب جزئي (راجع ADR-0006) — بدون منع خروج فعلي |
| نافذة عائمة بالخلفية | تظهر فورًا عند خروج التطبيق للخلفية أثناء جلسة نشطة |
| عمل أوفلاين بالكامل | شرط أساسي وغير قابل للتفاوض من اليوم الأول |
| أداء خفيف وموثوق | أولوية هندسية صريحة، خاصة بالخدمة الخلفية |
| نسخ احتياطي/استعادة محلي (Backup/Restore) | تصدير/استيراد كامل البيانات كملف JSON واحد — ضمن الـ MVP مباشرة، ليس مؤجّلًا |

## خارج النطاق (مؤجّل لنسخ لاحقة)

| الميزة | السبب |
|---|---|
| نظام مودات/جيمفكيشن (شخصيات تتطور) | يحتاج تصميم UX ونظام تطور مستقل. البنية التحتية للبيانات جاهزة لاستقباله لاحقًا دون migration (ADR-0005) |
| حسابات ومزامنة سحابية | ميزة اختيارية بالكامل لاحقًا، متعددة المنصات |
| وضع تركيز مطلق (منع خروج فعلي + كتم إشعارات) | قيود تقنية على أندرويد تتطلب موافقة مستخدم إضافية (Screen Pinning) — راجع ADR-0006 |
| تصدير CSV / بيانات خام | فجوة لوحظت عند منافس رئيسي (Focus To-Do)، تُضاف كتحسين لاحق |
| دعم iOS | راجع ADR-0001 |

## معايير الانتقال لنسخة لاحقة

يُعاد فتح أي بند "خارج النطاق" فقط بعد:
1. إطلاق MVP فعليًا على Google Play.
2. جمع ملاحظات استخدام حقيقية تؤكد الحاجة (أو عدمها) لهذا البند تحديدًا.
